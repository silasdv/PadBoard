# Privacy

PadBoard runs locally. It has no INTERNET permission, analytics or advertising.

As an input method, it receives context from the active editor. This context is used transiently for typing, capitalization, deletion and preview. Password text is not shown in the preview. Typed text is not intentionally persisted.

Stored preferences include language, theme, height, number row, haptics and gamepad mappings. The active application and Android system services have their own policies.

The optional Ko-fi button opens an external browser. Ko-fi and the browser apply their own privacy policies. PadBoard does not send typed text to them.

Uninstalling removes PadBoard's settings. Never include private input or passwords in public bug reports.
